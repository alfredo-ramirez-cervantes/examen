
frontend_ramirezCervantes

===============================

Este ForntEnd consume el servicio ramirezCervantes_backend que permite realizar las operaciones CRUD 

Información general
--------------------

1- Tener instalado Angular version 17 o superior

2- Descargar proyecto del repositorio

3- Ejecutar en una terminal  npm install

4- Ejecutar comando ng serve

5- Esto levantará en el navegador en http://localhost:4200/ .
